# Definition of Done

An item is Done only when all of the following are true. A draft is not Done.

- The editable source (.puml, .md or .feature) is committed and any exported PNG matches it.
- Terminology and identifiers (UC, FR, BR, GH, OC, CRC, IE/CR/CT, SD) match the baseline and traceability matrix.
- Another member has reviewed it, and review comments are resolved or recorded.
- Linked artefacts are updated together, so the use case, Gherkin, SSD, contracts, CRC, GRASP, DCD and sequence diagrams agree.
- Any significant design change is recorded in the decision log.
- The board card is moved to Done.
